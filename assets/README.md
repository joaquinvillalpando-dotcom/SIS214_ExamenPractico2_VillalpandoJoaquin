# Recursos multimedia

Esta carpeta reúne los recursos utilizados en la presentación del portafolio profesional interactivo.

## Estructura

| Carpeta | Recursos | Uso en el sitio |
| --- | --- | --- |
| `images/` | `foto-perfil.png`, `poster.png` | Fotografía del perfil y portada del video |
| `audio/` | `presentacion_personal.mp3`, `presentacion_personal.ogg` | Presentación personal reproducible en el navegador |
| `video/` | `video-hoja-vida.mp4`, `video-hoja-vida.webm` | Presentación audiovisual de la sección Multimedia |

## Formatos

Las alternativas MP3/OGG y MP4/WEBM permiten utilizar distintas opciones de reproducción según el navegador. La imagen `poster.png` se utiliza como portada del reproductor de video.

Los archivos multimedia se enlazan desde `index.html` mediante rutas relativas y forman parte del sitio publicado en GitHub Pages.
